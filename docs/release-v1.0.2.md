# v1.0.2 发布说明

本版修复两项安装恢复问题，并让提示词修订更容易发现。用户已授权完成修改、验证后发布。

## 修复

- 安装失败时只恢复本次尝试写入、当前内容仍可验证的资源。共享 marketplace 的外部新增内容不再被无条件恢复覆盖；写入后发生的外部修改保留并报告恢复冲突。
- 升级在“旧目录已移开、新目录尚未落位”时中断，可在确认进程退出、移除本项目遗留锁后用事务 ID 恢复。必须同时验证 displaced、stage 和备份，不能把任意目录缺失视为可恢复中断。

## 对话变化

- 灵活模式首次完整结果可在复制正文外附一句可选修改入口，不新增必答步骤；后续修订、严格模式及只要结果的请求不附加。
- 追加保留未改变的约束，替换废弃旧值，撤销恢复上一轮变更前的要求；新任务清除旧任务字段。新旧要求冲突时定向澄清。“直接使用”结束转换，不执行业务任务。
- 宿主发现严格模板与明确要求冲突时，先让用户选择灵活模式、修正 JSON 或接受限制，再交付结果。示例包括只读审查与开发实现步骤冲突，以及旧语言规则把“不要英文”判断为英文。

## 兼容与边界

严格 renderer、四套模板、32 组旧输出、CLI 默认值与参数不变。语义澄清依赖运行技能的宿主，直接 CLI 仍按旧规则拼接。旧 schema 1 安装事务继续可读；外部编辑冲突仍需明确合并，不强制覆盖。

Windows x64 继续按需准备校验后的官方 Python；不增加服务、数据库、依赖或强制 UI 控件。运行时登记仍用绝对路径，迁移目录后需要重跑安装器修复。不宣称网页、移动端或云端已验证。

测试范围及实际结果见[验证说明](validation.md)。下载整合包和 SHA256SUMS.txt，校验后解压运行 Install-Windows.cmd，再刷新宿主的 Auto Prompt 插件。其他两个 ZIP 分别用于插件和单技能分发，不含自动依赖准备入口。升级和回滚见[安装说明](install.md)。
