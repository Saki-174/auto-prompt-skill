## v1.1.1 发布验收

本版发布安装权限修复；此前“安装权限回归”一节保留本地评审阶段的日期、基线和状态，不表示发布后仍未提交。v1.1.1 最终源码以标签为准，发布包以本版附件及 SHA256SUMS.txt 为准。发布授权不代表真实客户端或全部平台验收通过；网页和本机插件需要各自在宿主刷新，不由 GitHub 发布自动更新。

发布版在 Windows、Windows PowerShell 5.1、专属 Python 3.13.16 上重新运行 **73 项单元测试：71 通过、2 跳过、0 失败**，并完成 **40 项离线 Windows 安装检查，全部通过**。两个跳过项为符号链接权限不足；未更改系统权限绕过。检查覆盖正式 v1.0.2 插件及单技能升级与回滚，32 组严格输出摘要保持兼容。

发布包通过成员白名单、CRC、逐文件源码比对和重复构建一致性检查；整合包 58 个成员、插件包 17 个成员、技能包 14 个成员。解压后的独立安装器和严格启动器自检通过，输出 SHA-256 为 `650b898d02661131657e3d3f502c7bf9d0e3c0ce1f47bca85257e76d725e52d2`。没有把本地日志、权限快照或机器配置加入附件。

首次远端候选 CI 在 Windows 私有 ACL 校验处停止；预期值中的数字 SID 与 Windows 输出的等价 SDDL 别名文本不一致。修订改用 Windows 原生转换统一 SID 表示后再作严格比较，新增真实目录创建及已知 SID 回归，不放宽访问权或省略校验。首次失败记录保留在 [候选 CI](https://github.com/Saki-174/auto-prompt-skill/actions/runs/37900838558)，最终发布使用修订后的提交与附件。

远端 CI 以 [v1.1.1 标签提交的工作流结果](https://github.com/Saki-174/auto-prompt-skill/actions)为准，矩阵包含 Windows/Linux 与 Python 3.13.16/3.14.8，另有 Windows 安装验收。首次发布前应确认对应提交的所有作业通过；矩阵通过也不等于 Linux 完整权限或真实 ChatGPT 对话验收。

## 网页版验证边界

网页版尚未完成记录环境、依赖条件、实际加载路径及工具调用的独立复现，不能将网页安装教程视为完整验收结果。

以下事项仍待验证：

- 未运行本机 Windows 安装器、未安装 Python 的隔离环境中，网页导入与调用是否可用。
- 空调用的完整引导、需求保留、生成后的替换与撤销，以及跨任务隔离。
- 结构化提示框与包内 Python 严格脚本的实际执行。
- 网页重复导入、更新、卸载、回滚，以及不同账号和浏览器的表现。

首次安装步骤见[网页与桌面安装教程](install.md)。[历史记录](history/validation-records.md)中的桌面本地安装与对话验收仅对应所列版本和环境，不能用于证明网页版能力。
