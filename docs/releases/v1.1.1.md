# v1.1.1 · Windows 安装权限修复

修复升级后自定义文件、事务备份和已有配置丢失私有 Windows DACL 的问题。原安装器保留字节内容，但新文件继承较宽父目录权限，可能让其他本机用户读取原本受保护的数据。

## 本版变化

- 创建事务目录和临时文件时即设置受保护的私有 DACL，写入内容前核验，备份副本保持私有。
- 程序重建、配置原子替换和回滚保留原 owner、primary group、DACL、保护标志及 ACE，保留空的自定义目录。
- 安装、目录切换、备份检查及恢复同时核对内容与权限；仅权限被后来修改时也停止并保留该修改。
- 新事务使用 schema 2 保存权限证据；读取、设置或核验失败时停止，不自动提权或放宽权限。
- 纳入 main 已合入的提示词约束保真、JSON 分流和来源核验规则，以及对应对话回归材料。固定模板、渲染器和 32 组旧输出摘要保持兼容。

## 下载与升级

Windows 本地安装使用 `auto-prompt-skill-1.1.1-bundle.zip`；校验 `SHA256SUMS.txt`，解压，关闭编辑器和插件管理器，运行 `Install-Windows.cmd`，再刷新本地插件并新建聊天。网页个人上传使用 `auto-prompt-skill-1.1.1-plugin.zip`，需要在网页条目中单独更新；本地安装或 GitHub 发布不会自动替换网页条目。

新安装器可以升级旧安装，并在开始时记录现有权限；此前已丢失的权限无法自动推导恢复。Windows 旧 schema 1 事务如需恢复已有文件，因缺少原 ACL 证据而拒绝自动回滚。保留活动目录、原事务和独立权限备份后人工核对，不用旧安装器强行绕过。新 schema 2 事务使用本版安装器和原事务 ID 恢复。完整步骤见[安装说明](../maintenance.md#失败与回滚)。

没有新增依赖、常驻服务或模型 API。运行时策略继续复用兼容解释器，或准备固定的项目专属 Python 3.13.16，不修改共享 Python、全局 PATH 或注册表。

## 验证与边界

本地权限修复已通过 73 项测试（71 通过、2 个符号链接场景因权限不足跳过）及 40 项 Windows 离线安装检查，包含正式 v1.0.2 两种模式升级与回滚。最终发布版本的测试、CI 和打包证据见[验证记录](../validation.md#v111-发布验收)，这些证据不替代真实宿主对话验收。

权限保证限于 owner、primary group 和 DACL；不承诺完整保留 SACL 审计、强制完整性标签、备用数据流或全部元数据。Windows AI/AR 继承记账标志不参与相等比较，保护标志和 ACE 继承位仍参与。外部进程不受安装器事务锁约束，也不提供突然断电的持久性保证。详细范围见[安全维护](../security-maintenance.md#安装权限保护v111)。

网页严格执行、跨平台完整权限适配和灵活输出的稳定质量仍需独立验收。已接受的旧提交邮箱残留继续准确披露，本版不再改写历史，不宣称旧对象已撤回。见[历史处置边界](../history/git-history.md)。
