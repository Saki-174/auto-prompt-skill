# v1.0.1 发布说明

用户于 2026-10-05 完成本地验收并明确批准发布。

Auto Prompt 现在面向 ChatGPT 本地宿主提供更轻量的安装与需求引导，生成的提示词可用于多个目标 Agent 和不同领域。

## 变化

- Windows x64 安装入口检查兼容 Python，缺失/不兼容时按需准备固定官方专属运行时；校验 SHA-256，不修改系统 Python 或 PATH。
- 程序归属清单、用户文件保留、冲突报告、幂等登记与事务备份；失败恢复和受保护回滚。
- 仅调用技能时启动分步引导；已给信息复用，关键歧义按依赖分轮追问；结构化输入不可用时文字回退。
- 改编 mattpocock/skills 中 grill-me → grilling 的澄清机制，保留 MIT 归属，不引入其工具依赖。
- 按任务组织开发、学习、研究、写作、视频等提示词，明确运行宿主与目标 Agent 的区别。

## 默认行为变化

自然语言日常使用默认改为灵活模式。完整旧 JSON 缺省 strictMode 及直接 CLI 的严格默认保留。原严格 renderer 和四套模板保持不变；确定性限于固定版本与模板下相同 JSON 的字节输出。

## 范围与限制

自动依赖准备只针对 Windows x64；其他平台保留既有手动 Python 路径，其他宿主的专门适配留待后续版本。宿主安装、登录、授权和最终插件启用仍需用户操作。运行时按需下载，不随整合包捆绑。

Windows 本机安装及用户确认的 ChatGPT 本地 Work 新对话已验收，详见[验证说明](validation.md)。无结构化工具及完全无脚本能力的真实客户端仍未验证，不宣称网页、移动端或云端兼容。

## 下载与安装

新电脑与升级均下载 `auto-prompt-skill-1.0.1-bundle.zip`，对照 `SHA256SUMS.txt` 校验，解压后运行 `Install-Windows.cmd`，再于宿主刷新并启用技能。另提供插件 ZIP 与单技能 ZIP；它们不包含自动依赖准备入口。

发布整理只更新说明文档；已验收的技能、安装脚本、严格模板及插件内容保持不变。完整整合包因文档更新具有新的 SHA-256，以正式 Release 附件为准。
