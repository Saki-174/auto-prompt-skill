# v1.0.1 最小方案与取舍

## 代码核验结论

开发基线：41c9f0e5a2dc820efcfea1dc0a14a92f8712aa55；实际工作区原为干净，远端 main 与本地一致。参考 v1.0.0 包也已核对 SHA-256。未假定历史报告就是当前安装状态。

原安装器选到第一个 Python 就执行，没有兼容性探测或依赖准备；更新复制整棵目录，虽然留下备份但替换了自定义文件；程序替换和 marketplace 写入分别进行，后者失败不能完整恢复。原技能默认严格，完整口语化跨领域交互与空调用引导不足。

修改模块：SKILL 与对话参考、Windows bootstrap、Python 文件安装事务、白名单打包、版本/说明及安装恢复测试。严格 renderer、四套模板和既有 CLI 输入协议保持不变。

## 运行时方案比较

| 方案 | 大小与网络 | 许可/来源与校验 | 维护 |
| --- | --- | --- | --- |
| 整合包附带 Python ZIP | 每包增加约 10.4 MB，首次安装可离线 | 需随包保留 PSF 及相关许可，固定官方来源及 SHA-256 | 每次运行时更新需重建大包 |

来源：[Python 3.13.12 文件与摘要](https://www.python.org/downloads/release/python-31312/)、[嵌入式包隔离说明](https://docs.python.org/3/using/windows.html#the-embeddable-package)。固定版本不表示永不更新；后续版本应审查并更新 lock，再做安装验收。当前不静默追踪 latest，不安装全局包管理器。

复用范围为 Python 3.9–3.14 且所需标准库探测成功；这是代码兼容检查，不能视为每个小版本和平台均完成了本地实测。过旧、未来未界定或无法执行的解释器不会被升级/卸载，自动路径转而准备专属固定版本。

## 可恢复升级

三类受管对象：程序目录、个人 marketplace 中的登记、项目运行时指针。预检归属和冲突，准备新树与旧态备份，写 applying 事务记录，再替换并核验，最后记 committed。捕获失败恢复 before；断电恢复见安装说明。记录旧/新摘要，回滚遇到后续编辑就停止。

自定义文件与程序文件分离；旧程序文件被修改时拒绝自动合并。未知配置版本和重复键拒绝解析，不丢字段。进程锁防止本项目两个安装器同时写入；宿主/其他插件并发改动仍应避免，升级前关闭使用插件的客户端，后续变化会导致回滚冲突。

## 对话机制

自然语言默认灵活模式；完整旧 JSON 与 CLI 仍保持原严格默认。只调用时收集缺失字段，已完整则直接生成；关键决策按依赖顺序分轮，非关键未知可留待确认。ChatGPT 当前可用的 request_user_input_async 参数已核验；其他环境在运行时检查工具定义，没有就文字提问。不写虚构的提示框 API。

用户指定 mattpocock/skills 的当前 grill-me 入口委托到 grilling；MIT 许可允许按其条件改编。取用决策依赖与分轮提问，控制问题数量，不继承其 Skill/子代理依赖或穷尽式访谈。参见技能内来源说明。

## 风险与验证

- 依赖下载失败/校验失败：必须失败退出；用官方 ZIP 离线恢复；实测损坏 ZIP 拒绝。
- 升级丢定制/覆盖其他配置：程序摘要与自定义保留、冲突拒绝、写失败恢复、重复安装/回滚测试。
- 文件系统链接误写：校验所有现有祖先和目标链接；拒绝 reparse/junction，所有递归删除只限已验证的受管目录。
- 宿主缓存没有更新：用户在新 ChatGPT 本地对话确认 v1.0.1；自动安装文件测试不替代。
- 模型问太多/乱猜能力：准备跨领域、多轮修改、未知回答、完整输入与工具回退的实际聊天验收用例。
- 发布误触：开发阶段仅生成本地候选，用户验证通过并明确批准后才发布。本版本已于 2026-10-05 获得用户批准。
