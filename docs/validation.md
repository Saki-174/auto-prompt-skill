## 2026-10-07 恢复与打包修订的新增检查

新增回归覆盖恢复复制中途、准备完成、目录移开/落位、共享文件原子替换前后及日志提交前的实际子进程退出；确认重试恢复完整旧态和用户文件，备份/中间证据篡改或之后的用户修改仍被保护。另覆盖普通恢复复制异常及安装失败后的恢复再次异常。

运行时测试用两个 PowerShell 进程验证准备入口被串行化、等待后重新探测；终止锁持有进程后真实安装器可重新获取锁，无需手工删运行时锁。Windows 集成验收增加同一空用户目录的双进程实际专属运行时准备，检查无嵌套 stage、同一解释器及锁释放。

新增打包来源测试覆盖目录符号链接、Windows junction及不安全的白名单路径；全部来源必须在任何ZIP写入前验证。损坏清单/事务的数组、null、缺字段、错误字段类型、无效摘要/路径及损坏JSON均检查明确失败、无堆栈且资源不变。

本地 Windows x64、PowerShell 5.1、Python 3.12.14 的本轮源码测试共49项，无失败；目录符号链接因本机权限限制跳过，junction实际检查通过。上轮同一恢复实现的46项Windows集成、24组故障重试序列和真实离线迁移已有证据。本轮最终整合包须另外执行测试与集成，正式提交的Windows/Linux × Python3.9/3.12四组CI必须通过后更新发布附件。

这些检查针对程序恢复与打包路径，不新增 ChatGPT 对话能力，也不代替新聊天验收或真实断电测试。原始运行日志、账户与机器配置仅保存在本地；正式CI结果以本修订提交关联的Actions为准。

## 自动化

~~~sh
python -m unittest discover -s tests -v
python scripts/build_release.py
~~~

保留 32 组旧严格输出摘要，以及 CLI、输入边界和原文保留检查。新增安装事务测试包括：独立用户文件与其他目录条目保留、管理文件冲突、路径冲突、重复安装、目录/运行时写入失败恢复、完整/中断事务回滚、后续编辑保护、备份篡改拒绝、重复 JSON、并发锁、链接路径拒绝和 Python 能力检查。

v1.0.2 新增回归包括共享登记并发修改（写入前、写入后、无需写入三种情况）、原子写入后异常、子进程实际退出在两次目录重命名之间，以及 stage/displaced/备份或状态不可信时拒绝恢复。

打包使用 scripts/package-files.json 的精确白名单，构建两遍核对字节重现性；不打入解释器、配置、机器日志、备份或源码目录外文件。

## Windows 集成验收

~~~powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File tests\windows_acceptance.ps1 -RuntimeArchive 'C:\downloads\python-3.13.12-embed-amd64.zip' -LegacyBundle 'C:\downloads\auto-prompt-skill-1.0.0-bundle.zip' -OutputDirectory 'C:\temporary\auto-prompt-evidence'
~~~

可加 -PreviousBundle 指向正式 v1.0.1 整合包，验证插件与单技能模式的真实升级、用户文件保留、重复安装和逐字节回滚。其固定 SHA-256 也会核对。

也可用 -AllowDownload 走实际官方下载路径。显式使用隔离的空用户根目录和 -DedicatedRuntime，防止测试意外复用开发机的全局 Python。测试覆盖离线首次准备、运行严格脚本、重装复用、兼容/不兼容解释器处理、损坏 ZIP、v1.0.0 升级与回滚，以及全局 PATH 不变。

该测试只模拟空目标用户目录，不等同于干净 Windows 虚拟机；系统组件、权限、杀毒软件和宿主登录仍来自实际机器。Python/PowerShell/OS 版本和实际测试结果应记录在本地交付报告中；未运行的平台明确留待验证。

现有 CI 矩阵保留 Windows/Linux × Python 3.9/3.12。发布需等待当前提交对应的四组检查通过，不把历史版本 CI 结果当作当前提交证据。
