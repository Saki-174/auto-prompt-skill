# v1.1.0 · 安全性修复

本版加强严格输出、安装目录切换、输入资源和运行时维护保护。开发基线为 `5778b49`；最终代码以 `v1.1.0` 标签为准。不新增常驻服务，对话规则与四套模板沿用 v1.0.2。

## 修复与维护

- 严格输出拒绝与输入共享文件身份的路径，包括硬链接。正常输出先写同目录临时文件，再原子替换，避免截断其他硬链接；替换失败保留原内容。
- 安装器移开旧目录后再次核对实际内容。并发编辑或读取失败时保留最新目录，报告冲突与事务 ID，不用较早备份覆盖新编辑。
- 未知 JSON 字段和重复键不回显原始键名。JSON 文件/标准输入限制为 1 MiB，目标 Agent 限制为 256 个 UTF-16 单位；深嵌套和无效 UTF-8 输入明确失败。
- 安装器、运行时登记和 Windows 严格启动器共用 Python 补丁策略。Windows 专属运行时锁定官方 Python 3.13.16，并校验固定 SHA-256。
- CI 的三个 Action 固定完整提交 SHA，权限保持 `contents: read`。补充常见私钥、证书容器的忽略规则、安全回归测试和历史定位文档。

## 升级与兼容

下载本版整合包及 `SHA256SUMS.txt`，校验后解压运行 `Install-Windows.cmd`，再刷新客户端插件。升级前关闭相关编辑器。自定义文件保留；程序文件被修改仍报告冲突，不强制覆盖。网页上传使用本版 plugin ZIP，账号入口与运行能力限制见[安装说明](../install.md)。

托管安装/启动接受 Python 3.11.17+、3.12.15+、3.13.16+、3.14.8+，仅限对应分支；3.9/3.10 和低于门槛的补丁不再复用。安装器自动准备专属运行时，不修改全局 Python、PATH 或注册表。离线升级需新版校验 ZIP 或兼容解释器；旧 ZIP 无法替代。

直接执行 renderer 没有新增此版本门槛。正常严格输出、旧 JSON 缺省、CLI 参数和模板保持兼容；32 组旧输出摘要用于验证。输出原子替换会改变文件身份及权限属性，详见[维护说明](../security-maintenance.md)。恢复与回滚步骤见[安装说明](../maintenance.md#失败与回滚)。

## 验证与限制

实际测试环境、结果及未验证事项见[验证记录](../validation.md)。发布前运行最终整合包的自动测试和 Windows 隔离安装/升级/回滚检查，并核对发布提交的 Windows/Linux × Python 3.13/3.14 四组 CI。

本版没有修改对话规则，未重新执行真实 ChatGPT 网页/桌面聊天验收；网页严格执行与结构化提示框仍待验证。安装器保护不能约束持有旧文件句柄的外部进程持续写入，也不构成突然断电持久性保证。

历史邮箱的当前分支与标签已使用 noreply，但已知旧提交仍可公开读取。该残留本次不继续处理，没有发送 Support 申请；不把邮箱视为登录凭据，不展示旧邮箱，不宣称彻底撤回。见[历史定位与处置边界](../history/git-history.md)。
